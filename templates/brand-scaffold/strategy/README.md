# Strategy

This README explains the folder. It is not one of the folder's docs, so leave it out of any list or index of them.

What the brand has decided to do, once the team approves it.

## What lives here

- `product-priority.md`: which products to push, and why.
- `strategic-roadmap.md`: the plan the creative work serves.
- The inputs the roadmap is built from: the persona, messaging and creator talent strategy.

The prompts that write these docs are in `parker-system/prompts/strategic-roadmap/`. They read the foundation, the personas, the competitors and the audits, so they run after those.

A new brain starts with this folder empty. The build fills it in Phase 2, after the team approves the strategy.
