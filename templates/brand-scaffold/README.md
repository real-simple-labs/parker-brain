# {{BRAND_NAME}}'s Parker brain

This is {{BRAND_NAME}}'s brand brain: the folder Parker thinks with. It's set up but not built yet. The method, the skills, and the routines are all here; the brand's own knowledge (the audit, the customers, the competitors, the strategy) hasn't been written yet.

## Where to start

- **Build it.** Open this folder in Claude Code or Codex (Parker Desktop does this for you) and run `/set-up-brain`. Parker connects to the brand's data, asks a few questions only the team can answer, and builds the rest. It takes a few hours, mostly on its own.
- **Or just start talking.** Parker works on an unbuilt brain too. It pulls live data from the ad account, reviews, and competitors as it goes, and saves what the team tells it into `running-notes/` and `brand-lens.md`, so the brain starts filling in from day one.
- **Want the tour?** Run `/get-started` any time.

## What's here now

- `CLAUDE.md`: how Parker works in this brain. `AGENTS.md` is the same entry point for Codex.
- `parker-system/`: Parker's method library (prompts, craft knowledge, system docs), mounted read-only and pinned to a release.
- `.claude/skills/`: the craft skills (scripts, hooks, headlines, iterations, account analysis) and the routines that keep the brain fresh.
- `running-notes/`: the team's notes, rules, and what Parker still needs to know. Empty until the team starts talking.
- `brand-lens.md`: the brand's own rules and tribal knowledge. Empty until it's filled.
- `.scaffolded`: marks this brain as not built yet. It comes off on its own once the build finishes its first phase.

The Parker Desktop app keeps this folder saved and synced for the whole team.
