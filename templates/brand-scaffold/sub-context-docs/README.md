# Sub-context docs

This README explains the folder. It is not one of the folder's docs, so leave it out of any list or index of them.

The foundation reads of the brand: the slow-changing facts that every answer stands on.

## What lives here

- One doc per slice: brand identity, website and product, category and market, competitive landscape, customer journey and persona discovery, community and forums, reputation, organic channels, the ad account, performance targets and metrics, marketing calendar and campaigns, operations and team.
- `brand-profile-narrative.md`: the slices drawn together into one account of the brand.
- `visual-vocabulary.md`: the brand's filmed shot library: the shots in play, the adjacent ones, and what is out of play.

The prompts that write these docs are in `parker-system/prompts/brand-profile/`. To refresh a doc, re-run its prompt instead of editing it from memory. The visual vocabulary's method is `parker-system/creative-strategy-context/visual-vocabulary-method.md`.

A new brain starts with this folder empty. The build fills it.
