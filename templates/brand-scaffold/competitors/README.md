# Competitors

This README explains the folder. It is not one of the folder's docs, so leave it out of any list or index of them.

One folder per rival: how they sell, what they run, and what their customers say about them.

## What lives here

- `_competitive-set.md`: the rivals this brain tracks. It starts from the competitor list the team gave at intake.
- `[competitor]/`: one rival's profile, one doc per read: snapshot, brand identity, website and product, ad account, organic channels, reputation, reviews and customer language, community and forums, customer and persona discovery, running notes, and the working thesis that draws them together.
- `INDEX.md`: the generated map of the set, one line per rival. `/refresh-context` keeps it in step with the folder.

The prompts that write these docs are in `parker-system/prompts/competitor-profile/`. How to read a rival's ads is in `parker-system/creative-strategy-context/analyzing-public-ad-accounts.md`.

A new brain starts with this folder empty. The build fills it.
