# Briefs

This README explains the folder. It is not one of the folder's docs, so leave it out of any list or index of them.

The brand's own brief format.

## What lives here

- `_brief-template.md`: the team's brief format, saved word for word from the intake when they gave one. It shapes every brief Parker writes for this brand.

The briefs written for a round live in that round's folder, `../sprints/[YYYY-MM-DD]-[sprint-slug]/briefs/`. The prompt that writes them is `parker-system/prompts/ideas-and-briefs/brief-creation.md`.

A new brain starts with this folder empty. The intake fills it when the team shares their brief format.
