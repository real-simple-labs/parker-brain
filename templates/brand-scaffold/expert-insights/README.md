# Expert insights

This README explains the folder. It is not one of the folder's docs, so leave it out of any list or index of them.

Outside expertise the team hands Parker, such as a talk, an article or a course, studied before any of it changes how Parker works for this brand.

## What lives here

- `inbox/`: one receipt per source: where it came from, and its limits.
- `context-update-candidates/`: the exact changes Parker proposes from a source, waiting for the team to approve them.
- `curation/`: the monthly and quarterly passes that group the saved signals and pick which repeated ones should change how Parker works.

Nothing here changes a doc or a skill by itself: a change happens only after the team approves it. The skill is `.claude/skills/expert-signal-intake/`, and the factory's own intake, with the same folders, is in `parker-system/creative-strategy-context/expert-insights/`.

A new brain starts with this folder empty.
