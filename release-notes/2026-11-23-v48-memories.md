# v48 — the brain reads Parker memories (2026-11-23)

Parker memories are the short facts and rules a team saves in Parker (Settings → Memories, or chat): "never say cheap", "briefs focus on the hook and the production style". Parker's web and Slack chat reads them on every message. Since 2026-11-23 Parker's server also keeps them as files, one `.md` file per memory, in a `memories/` folder of the matching repo: brand memories in the brand's brain, organization memories in the organization's shared folder, a person's own memories in their personal folder. The sync goes both ways: an edit in Settings changes the file, and a file edited, added, renamed or deleted in the brain changes the memory.

A session in the brain (Claude Code or Codex) did not know about them: the factory still said that the Claude Code stand-in for `update_custom_working_memory` was "the output doc and `running-notes/`".

## What shipped

- **The session start hook reads the memories in.** `session-start.py` reads `memories/` (this brand), `../memories/` (the organization's folder, when the brain sits at `orgs/<org>/<repo>/` in Parker Desktop) and `../../../personal/memories/` (the person's own; `../../personal/` for the layout before Desktop 0.1.18). It takes the same files Parker's server syncs: `.md` files directly in the folder, not `README.md`, not hidden files. It pastes up to about 3,500 bytes of memory text, quoted as data, and names the files past that so the agent reads them; Codex moves hook output past about 2,500 tokens into a temporary file, and `.parker/access.md` shares the room. A cloud run's clone has only the brain's own folder. The hook runs again after a compaction, so the memories come back too.
- **Saving a memory from the brain.** The hook, `AGENTS.md` and the brand `CLAUDE.md` template say how: one short file in the right `memories/` folder, one fact per file, at most 4,000 characters. Parker syncs it into its memories in a few minutes. `system/parker-tools.md` names this as the stand-in for `update_custom_working_memory`.
- **How to treat them.** Like `running-notes/brand-rules.md`: the team's standing rules, followed on every reply; when one clashes with what the person asks now, the person wins.

## Migration

`migrations/v48.md`: nothing to do. The re-sync refreshes the hook and `AGENTS.md`; standing brains' `CLAUDE.md` keeps its map (the hook carries the rule). The `memories/` folders come from Parker's server.
