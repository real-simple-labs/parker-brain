# Process — Build the Swipe File

Assemble or refresh a queryable library of statics worth stealing from, organized by format tag. The value is speed later: "we need a post-it note static" becomes a five-minute job instead of an afternoon of re-finding the same ads.

## When to pick

- Standing up a brand's creative reference for the first time.
- Refreshing before a production push, or when a format gap has just been identified and there is no reference for it.
- When the same ads keep being re-found from scratch.

## Execution

1. **Name the brands to pull from.** Tracked competitors, inspo brands, and affinity brands — the last being brands that share this audience without sharing the category, which are often the richest source because their mechanisms transfer without the result looking derivative.
2. **Query by format tag, sorted by impression rank.** Filter to statics. The tags are the ones in `ad-formats/static/index.md` and `ad-formats/both/index.md` — using the same vocabulary as the account's own tagging is what makes the file queryable later.
3. **Filter to what is actually holding rank.** Rank history over days beats a single snapshot. An ad that touched the top once is noise.
4. **Keep the provenance.** For each saved ad: the brand, the format tag, the rank and its history, the launch date, and a link back to both the ad library and the Parker record. A swipe entry without provenance is a screenshot nobody can act on later.
5. **Write down why it was saved.** One line on the mechanism — why this works — not a description of what it looks like. That line is what a strategist reads later to decide whether it applies.
6. **Save it back.** Persist to the brand's swipe file so it is queryable rather than living in a chat log.

## Output content

- The brands pulled from and the format tags queried.
- Per entry: brand, format tag, rank and history, launch date, links, and the one-line mechanism.
- What was deliberately excluded and why.

## What never to do

- Save an ad without its mechanism note. A picture with no reasoning is not a swipe file.
- Save on a single-snapshot rank.
- Mix video into a static swipe file without tagging it as such.
- Restrict the pull to direct competitors. Affinity brands are usually where the transferable mechanisms are.
- Leave the file in the conversation instead of persisting it.
