# Process — Reverse-Engineer a Winning Static

Take an external static that is holding a top impression rank and rebuild what makes it work, using this brand's copy, proof, and customer language. You cannot see inside another brand's ad account, but impression rank is a usable proxy — an ad sitting at the top of a brand's library across multiple days probably has spend behind it.

## When to pick

- **Best for:** brands whose own static corpus is thin, categories where a competitor has visibly found something, and gaps the account has no internal precedent for.
- **Worst for:** situations where the brand already has a proven winner in that format. Adapt the internal winner instead — it is measured, the competitor's is inferred.

## What impression rank does and does not tell you

Read `public-ad-library-analysis.md` before leaning on it. In short: rank is a proxy for impressions, which is a proxy for spend, which is a proxy for performance. Rank held steadily over a week is a stronger signal than a single snapshot. Rank tells you nothing about the ad's efficiency, its audience, or whether it is profitable.

## Execution

1. **Pull the field.** Top statics by impression rank from tracked competitor, inspo, and affinity brands. Affinity brands — same audience, different category — are often the richest source, because their mechanisms transfer without the ad looking derivative.
2. **Read the rank history, not the rank.** An ad stable at #1 over eight days is a different signal from an ad that touched #1 once.
3. **Name the mechanism.** In a sentence: why does this ad work? What does it want the viewer to believe, and how do the copy and layout build that belief? This is the thing being borrowed. Everything else is surface.
4. **Check the mechanism transfers.** A mechanism that depends on an asset this brand lacks — a category-specific proof, a visual only their product supports — does not transfer, however well it performs for them.
5. **Rebuild with this brand's material.** Every word is rewritten. The copy comes from this brand's reviews and comments, per `static-from-customer-language.md`. Match the original's copy mechanics — if it used a number, use a number; if it asked a question, ask a question — and match its word count at every level. Bloat kills recreations.
6. **Do not redesign the layout.** The structural skeleton is what is being borrowed. Copy and brand-specific visuals change; the skeleton stays. `static-ad-recreation.md` is the full method.
7. **Run the stranger test** on the rebuilt headline. The original passing it does not mean the rebuild does.

## Output content

- The source ad: brand, format tag, current rank, rank history, launch date, and a narrative description a reader who never saw it could picture.
- The mechanism, in one or two sentences.
- The rebuild, copy element by copy element — original beside this brand's version, as prose.
- What did not transfer and why.

## What never to do

- Copy the surface. The mechanism transfers; the words never do.
- Treat a single-snapshot rank as evidence.
- Let the rebuild run longer than the original.
- Add elements the original did not have — a CTA button, an extra proof line — because they seem like improvements.
- Redesign the layout and call it a recreation.
- Recreate an ad from a brand whose category advantage the brand cannot match.
