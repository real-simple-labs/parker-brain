# v15 — git auth moves to the machine-level `@heyparker/sync` helper

**Applies to:** brains pinned at `v14` or earlier.

**What changes:** the per-repo credential layout from `v8`/`v10` (`.git/parker-credentials` + a repo-local two-entry `credential.helper`) is retired. Auth is now a machine-level git credential helper installed once by `npx @heyparker/sync setup`; git fetches a short-lived, single-repo credential from Parker per operation, and no agent ever handles a token again. The updated skill, hooks, and settings travel inside the copied bundle — the pin bump's re-sync delivers them. The steps below are the two things the re-sync cannot do: set up the *machine*, and clean this *repo's* retired wiring.

## Steps

1. **Machine setup (once per machine, needs the user present).** If `~/.parker/bin/parker-credential` already exists, skip this step. Otherwise run:

   ```bash
   npx @heyparker/sync setup
   ```

   It opens a browser sign-in to Parker and wires the helper into the user's global git config, scoped to `https://github.com/parker-brain/` only. **Headless or scheduled run with nobody present:** stop here — leave the legacy wiring in place (it keeps working until its token expires), note in `running-notes/standard-sync.md` that v15's machine setup is pending an interactive session, and finish the rest of this migration in that session. Do not delete the old wiring before the helper exists.

2. **Clean this repo's retired wiring (idempotent; no command carries a secret).** Only after step 1 confirms the helper is installed:

   ```bash
   git config --local --unset-all credential.helper
   rm -f .git/parker-credentials
   ```

   Both are safe to re-run; "no such section" from the first command just means it was already clean. If `git remote get-url origin` shows `x-access-token:` embedded in the URL (a pre-v8 brain), also strip it: `git remote set-url origin https://github.com/parker-brain/<repo>.git`.

3. **Verify.** After the pin bump's re-sync finishes, `git fetch origin` should succeed with no prompts and no credential files on disk. If it fails auth: re-check step 1 (helper installed?), then `/save-brain`'s auth ladder.

Record migrations through `v15` and set `parker_brain_version` to `v15` as usual.
