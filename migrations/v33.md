# v33 — a cloud run saves through the factory script

**Applies to:** every brain.

**What changes:** a cloud run that started in the factory (a scheduled routine) saves with one allowed command, `scripts/cloud-run-git.py save`, instead of raw git, so auto mode's safety check never has to judge a fetch or push to the brain. The re-sync delivers `save-brain`, `setup-routines` and the brand `AGENTS.md`. The brain's own `CLAUDE.md` is a seed that the re-sync never touches, and its cloud-run sentence names the raw push, so step 1 changes that sentence. Routines armed with a v27 to v32 prompt keep saving the way they did: their preamble says to save "as the copy's `save-brain` says", which names `save` once the brain is on v33, but the same sentence still shows the raw `git push origin HEAD:main` in brackets. Only `/setup-routines` changes a stored prompt, so step 2 offers it. It stays an offer: many teams switched Parker's routines off or run their own.

## Step 1 — the cloud-run sentence in CLAUDE.md

In `CLAUDE.md`, replace every copy of this text (it is in the file once or twice):

```
pushes straight to `main` itself (`git push origin HEAD:main`; it has permission to, and never makes a branch), per `/save-brain`'s "In a cloud run"
```

with:

```
pushes straight to `main` itself (it has permission to, and never makes a branch), the way `/save-brain`'s "In a cloud run" says
```

If the text isn't there (the team rewrote the sentence, or the brain is older than v24), skip this step. Change nothing else in `CLAUDE.md`.

Verify: this prints `ok`.

```
grep -qF '(`git push origin HEAD:main`; it has permission to' CLAUDE.md && echo "the old sentence is still there" || echo ok
```
