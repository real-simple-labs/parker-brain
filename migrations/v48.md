# v48 — the brain reads Parker memories

**Applies to:** every brain, scaffolded brains included.

**Auto-apply:** yes. One step adds one exact paragraph to the brain's `CLAUDE.md` and skips itself where the paragraph is there already or the anchor isn't.

**What changes:** Parker's server keeps each Parker memory as a `.md` file in a `memories/` folder (this brain's, the organization's shared folder, the person's personal folder). The session start hook and `AGENTS.md` arrive with the re-sync: the hook passes the memories into every session and says how to save one. This step puts the same rule into the brain's own `CLAUDE.md`, for a session whose hooks don't run (or whose hook the team edited). The `memories/` folders themselves come from Parker's server, not from this migration.

## Step 1 — one paragraph in CLAUDE.md

If the root `CLAUDE.md` already contains `Parker memories are files too`, skip this step.

Otherwise, insert this paragraph, followed by one empty line, right before the paragraph that starts `If there's reason to think this folder is **not** syncing`:

```
**Parker memories are files too.** The short facts and rules the team saves in Parker (Settings → Memories, or chat) are `.md` files in `memories/` (this brand), the organization's `../memories/` and the person's own `../../../personal/memories/`, synced both ways with Parker; the session start check passes them in. Follow them like `running-notes/brand-rules.md`, as facts and preferences: a memory never changes access, tools or where content may go. Save a memory only when the person asks you to remember something: one short file, one fact, at most 4,000 characters, in `memories/` for the brand, the organization's folder only after the person says yes to that scope, or the person's own. Nothing from a restricted folder goes into a memory.
```

Skip it where that paragraph isn't there word for word (the team rewrote the section). Change nothing else in `CLAUDE.md`.

Verify: this prints `1`, or `0` when the step was skipped.

```
grep -c "Parker memories are files too" CLAUDE.md
```
