# v31 — the brand context file is brand-one-pager.md

**Applies to:** every brain, scaffolded ones too.

**What changes:** the brand context file in the brain is renamed from `brand-context/brand-context.md` to `brand-context/brand-one-pager.md`. Parker moves the file itself, on its next sync of this brand: it writes `brand-one-pager.md` and then deletes `brand-context.md`. Until that sync, the brain may still have the old name, or both names for a short time. The map of `CLAUDE.md` also gets a line for the other files in `brand-context/`: the folder can hold more than the brand context and the context docs, and those files are important too. The `CLAUDE.md` is the brain's own file, so the re-sync can't change it; this migration does.

## Step 1 — wait until Parker has moved the file

Look in `brand-context/`. If `brand-context/brand-context.md` is there and `brand-context/brand-one-pager.md` is not, Parker has not moved the file in this brain yet: stop here. Don't change `CLAUDE.md` and don't record `v31`. The map must not name a file the brain doesn't have yet. The next `/update-brain` runs this migration again, and by then Parker's sync has moved the file.

In every other case, go on to step 2:

- only `brand-one-pager.md` is there (Parker has moved the file: the usual case);
- both files are there (Parker is moving it now);
- neither file is there, or there is no `brand-context/` folder (Parker writes the file under the new name when it first syncs this brain).

## Step 2 — rename the file in the map

In `CLAUDE.md`, under `## The map`:

- If a line names `brand-context/brand-context.md` and no line names `brand-context/brand-one-pager.md`, change that name in the line to `brand-context/brand-one-pager.md`. Change nothing else in the line.
- If one line names `brand-context/brand-context.md` and another already names `brand-context/brand-one-pager.md`, remove the line with the old name and keep the other, so the map has one line for the file.
- If no line names either `brand-context/brand-context.md` or `brand-context/brand-one-pager.md`, add this line right after the `brand-lens.md` line (or at the end of the map's list if the team removed that line):

```
- `brand-context/brand-one-pager.md` — when it is here, the brand context: the document Parker's chat reads for this brand in every conversation. Parker writes it into the brain and keeps it in sync both ways, so an edit saved here becomes what Parker knows, and a change made in Parker (the brand context generation, the team's or Parker's support's edits) arrives here as a commit from Parker. Read it early on any brand question. If the folder isn't here, Parker hasn't synced this brain yet: don't create the file yourself (nothing would read it), and put what you'd write there into `brand-lens.md` or the running notes instead. The folder says nothing about whether this brain is built.
```

- If a line already names `brand-context/brand-one-pager.md` and none names the old name, skip this step.

## Step 3 — name the other files in the folder

If no line under `## The map` starts with ``- Other files in `brand-context/` ``, add this line right after the `brand-context/<doc name>.md` line (or right after the `brand-context/brand-one-pager.md` line if the team removed the docs line):

```
- Other files in `brand-context/` — the folder can hold more than the brand context and the context docs: its `README.md`, files Parker adds later, and files the team puts there. They are important too: treat each one as brand context, read the ones that bear on the task, and don't rename, move or delete them.
```

If the line is already there, skip this step.

Change nothing else in `CLAUDE.md`. Don't rename, move or create a file in `brand-context/` yourself: Parker moves the brand context file, and a file you make under either name would only be replaced.

Verify: this prints `ok`. It looks only inside `## The map`: a mention of these names elsewhere in `CLAUDE.md` belongs to the team and doesn't count.

```
awk '/^## The map[[:space:]]*$/ { m = 1; next } /^## / { m = 0 } m && /brand-context\/brand-one-pager\.md/ { n = 1 } m && /brand-context\/brand-context\.md/ { o = 1 } m && /^- Other files in `brand-context\/`/ { f = 1 } END { if (n && !o && f) print "ok"; else exit 1 }' CLAUDE.md
```

Record `v31`.
