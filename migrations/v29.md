# v29 — the brand context is a file of the brain

**Applies to:** every brain, scaffolded ones too.

**What changes:** Parker keeps this brand's brand context (the document its chat reads in every conversation) as `brand-context/brand-context.md` in the brain. It is an ordinary tracked file: Parker commits its own changes to it, and an edit the team saves here becomes what Parker knows. Parker writes the file itself on its first sync, which may come after this release; until then the folder isn't there, and the map line says so. This migration doesn't create the file. It only tells the brain's `CLAUDE.md` where the file is. The `CLAUDE.md` is the brain's own file, so the re-sync can't add the line; this migration does.

## Step 1 — name the folder in the map

In `CLAUDE.md`, under `## The map`, check whether a line already names `brand-context/brand-context.md`. If one does, skip this step.

Otherwise add this line right after the `brand-lens.md` line (or at the end of the map's list if the team removed that line):

```
- `brand-context/brand-context.md` — when it is here, the brand context: the document Parker's chat reads for this brand in every conversation. Parker writes it into the brain and keeps it in sync both ways, so an edit saved here becomes what Parker knows, and a change made in Parker (the brand context generation, the team's or Parker's support's edits) arrives here as a commit from Parker. Read it early on any brand question. If the folder isn't here, Parker hasn't synced this brain yet: don't create the file yourself (nothing would read it), and put what you'd write there into `brand-lens.md` or the running notes instead. The folder says nothing about whether this brain is built.
```

Change nothing else in `CLAUDE.md`.

Verify: this prints `ok`.

```
grep -q 'brand-context/brand-context.md' CLAUDE.md && echo ok
```

## Step 2 — leave `parker-context/` alone

v25 added `parker-context/` to `.gitignore` for an earlier plan; nothing uses that folder now. Don't remove the line and don't move anything: an ignored line for a folder that isn't there does nothing.

Record `v29`.
