# v32 — a README in each folder the brain fills

**Applies to:** every brain, scaffolded ones too.

**What changes:** a new brain now starts with a short `README.md` in each of the ten folders the build and the team fill. Each README says what the folder will hold and which `parker-system/` prompts and skills write it. The scaffold writes them into new brains only. They are seeds (brand-owned, written once), so this migration adds them to a standing brain, and never overwrites a README the brain already has. The map of `CLAUDE.md` also gets one line: a folder's README is never one of its docs.

## Step 1 — add the missing folder READMEs

For each folder below, if `<folder>/README.md` does not exist, copy `parker-system/templates/brand-scaffold/<folder>/README.md` to `<folder>/README.md`, creating the folder if it isn't there. If `<folder>/README.md` already exists, leave it as it is: it is the team's, or a skill wrote it (`idea-bank/README.md` may be the idea bank's own "how to use" page).

- `sub-context-docs`
- `personas`
- `source-pulls`
- `competitors`
- `audits`
- `strategy`
- `idea-bank`
- `sprints`
- `briefs`
- `expert-insights`

Copy each file as it is. Don't edit it, don't add the brand's name to it, and don't move or rename anything else in these folders.

## Step 2 — say in the map that a README is not a doc

If `CLAUDE.md` has no `## The map` heading (the team restructured the file), skip this step and tell the team why: the paragraph belongs under that heading, and the READMEs step 1 copied say the same in their first line (a README the brain already had may not). Don't recreate the heading.

In `CLAUDE.md`, if `## The map` has no line that starts with `Most folders below have a`, add this paragraph right under the `## The map` heading, before its list:

```
Most folders below have a `README.md` that says what the folder holds and which prompts write it. A README is never one of the folder's docs: leave it out of any list or index of them.
```

If the line is already there, skip this step. Change nothing else in `CLAUDE.md`.

## Step 3 — keep the indexes clean

If `competitors/INDEX.md` or `audits/INDEX.md` lists the folder's `README.md` as an entry, remove that one line. Change nothing else in the index.

Verify: this prints `ok`. A `CLAUDE.md` with no `## The map` heading passes the map part, as in step 2.

```
for d in sub-context-docs personas source-pulls competitors audits strategy idea-bank sprints briefs expert-insights; do [ -f "$d/README.md" ] || { echo "missing $d/README.md"; exit 1; }; done; awk '/^## The map[[:space:]]*$/ { m = 1; s = 1; next } /^## / { m = 0 } m && /^Most folders below have a/ { f = 1 } END { if (f || !s) print "ok"; else { print "the map has no README line"; exit 1 } }' CLAUDE.md
```
