# v30 — the brand context file is brand-one-pager.md

**Applies to:** every brain, scaffolded ones too.

**What changes:** the brand context file in the brain is renamed from `brand-context/brand-context.md` to `brand-context/brand-one-pager.md`. Parker moves the file itself, on its next sync of this brand: it writes `brand-one-pager.md` and then deletes `brand-context.md`. Until that sync, the brain may still have the old name, or both names for a short time. This migration only renames the file in the map of `CLAUDE.md`. The `CLAUDE.md` is the brain's own file, so the re-sync can't change the line; this migration does.

## Step 1 — rename the file in the map

In `CLAUDE.md`, under `## The map`:

- If a line names `brand-context/brand-context.md`, change that name in the line to `brand-context/brand-one-pager.md`. Change nothing else in the line.
- If no line names either `brand-context/brand-context.md` or `brand-context/brand-one-pager.md`, add this line right after the `brand-lens.md` line (or at the end of the map's list if the team removed that line):

```
- `brand-context/brand-one-pager.md` — when it is here, the brand context: the document Parker's chat reads for this brand in every conversation. Parker writes it into the brain and keeps it in sync both ways, so an edit saved here becomes what Parker knows, and a change made in Parker (the brand context generation, the team's or Parker's support's edits) arrives here as a commit from Parker. Read it early on any brand question. If the folder isn't here, Parker hasn't synced this brain yet: don't create the file yourself (nothing would read it), and put what you'd write there into `brand-lens.md` or the running notes instead. The folder says nothing about whether this brain is built.
```

- If a line already names `brand-context/brand-one-pager.md` and none names the old name, skip this step.

Change nothing else in `CLAUDE.md`. Don't rename, move or create the file in `brand-context/` yourself: Parker moves it, and a file you make under either name would only be replaced.

Verify: this prints `ok`.

```
grep -q 'brand-context/brand-one-pager.md' CLAUDE.md && ! grep -q 'brand-context/brand-context.md' CLAUDE.md && echo ok
```
