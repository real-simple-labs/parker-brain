# v44 — the brain knows which folders only some people see

**Applies to:** every brain, scaffolded brains included.

**Auto-apply:** yes. One step adds one exact paragraph to the brain's `CLAUDE.md` and skips itself where the paragraph is there already or the anchor isn't.

**What changes:** Parker Desktop now writes `.parker/access.md` at the brain's root for the person signed in (never synced): the restricted folders, who sees each one, and who sees the rest. The session start hook and `AGENTS.md` arrive with the re-sync and pass the rule and the file to every session. This step puts the same rule into the brain's own `CLAUDE.md`, for a session whose hooks don't run.

## Step 1 — one paragraph in CLAUDE.md

If the root `CLAUDE.md` already contains `.parker/access.md`, skip this step.

Otherwise, insert this paragraph, followed by one empty line, right before the paragraph that starts `If there's reason to think this folder is **not** syncing`:

```
**Some folders are only for some people.** A team can restrict a folder to the people it picks; for everyone else the folder isn't in their copy, and nothing in the files says so. Parker Desktop writes `.parker/access.md` at this brain's root for the person signed in here (never synced; the session start check passes it in): the restricted folders, who sees each one, and who sees the rest. Content from a restricted folder stays in it: don't copy, quote or sum it up in a folder more people see unless the person says yes after you tell them who will then see it. Answer "who can see this" from that file; with no file, say you don't know, never "everyone". Who sees a folder changes only in Parker Desktop ("Who can see this folder").
```

Skip it where that paragraph isn't there word for word (the team rewrote the section). Change nothing else in `CLAUDE.md`.

Verify: this prints `1`, or `0` when the step was skipped.

```
grep -c "Parker Desktop writes \`.parker/access.md\` at this brain's root" CLAUDE.md
```

Record `v44`.
